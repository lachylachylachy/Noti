# What Noti Is Not

This file exists to protect the product direction.

## Noti Is Not a Notion Clone

Noti should not become a nested-page database tool.

Avoid:

- excessive tables
- page/database sprawl
- heavy templates
- too much manual organisation

## Noti Is Not a Trello Clone

Boards can exist, but Noti should not become primarily card columns.

Avoid:

- board-first thinking
- operational clutter
- rigid project-management workflows

## Noti Is Not an Obsidian Clone

Noti can support knowledge and connected notes, but should not become a graph-heavy markdown vault.

Avoid:

- dense file trees
- graph-first workflows
- overwhelming knowledge-base mechanics

## Noti Is Not a Full IDE

Code Space should help developers think, capture implementation notes, manage snippets, and connect code context.

It should not try to replace VS Code immediately.

Avoid:

- becoming a generic Electron IDE
- overbuilding compiler features too early
- complex language tooling before the workspace model is stable

## Noti Is Not an AI Chatbot Wrapper

AI should not dominate the product.

Avoid:

- large assistant panels everywhere
- forced AI replies
- automatic workflow changes without consent
- turning every note into a chatbot conversation

AI should feel environmental, contextual, and optional.

## Noti Is Not a Dashboard

Avoid making the homepage a dense overview of everything.

Noti should feel like a workspace, not a metrics/control panel.

## Noti Is Not a Plugin Marketplace Yet

Integrations should be curated and deeply contextual.

Avoid adding endless services before the core product is stable.
