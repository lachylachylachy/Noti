# Noti Vision

## Core Idea

Noti is a calm, spatial productivity workspace for thinking, planning, coding, and organising work.

It is not a traditional notes app, project manager, calendar app, or IDE. It is one adaptive desktop environment where the workspace changes around the user’s current context.

The central product idea is:

> One thread-based workspace that adapts visually and functionally depending on what the user is doing.

A coding thought should naturally open into a code-focused workspace. A planning thought should surface calendar and reminder tools. A project thought should expand into board or timeline views. The user should not feel like they are switching between separate apps; they should feel like the same environment is reshaping itself around the work.

## Product Feel

Noti should feel:

- calm
- premium
- spatial
- minimal
- focused
- native-desktop-first
- low-noise
- visually soft but structurally sharp

The app should feel closer to a personal productivity OS than a dashboard.

## Design Inspiration

Useful references:

- Apple visionOS glass interfaces
- Apple Calendar readability
- Apple Music glass/panel layering
- Linear restraint and density control
- VS Code’s focused developer ergonomics
- ChatGPT’s conversational flow
- Freeform/Figma-style spatial flexibility, used carefully

Noti should borrow principles, not clone products.

## Long-Term Direction

The long-term direction is an adaptive productivity environment where notes, code, calendar, reminders, boards, integrations, and AI suggestions all orbit the same underlying thread model.

The product should prioritise continuity over feature volume.

Every new feature should answer:

> Does this make the workspace feel more context-aware, more useful, and less noisy?
