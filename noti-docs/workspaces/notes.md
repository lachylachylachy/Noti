# Notes Workspace

## Purpose

The Notes workspace is the default thinking surface.

It should let the user quickly capture thoughts, ideas, tasks, plans, and reflections without forcing structure upfront.

## Core Feel

Notes should feel conversational, calm, and lightweight.

The main composer can feel similar to ChatGPT’s “What’s on your mind?” style input, but Noti should not feel like a chatbot-first product.

## Behaviour

A note can become more structured over time.

Examples:

- simple thought → stays as note
- task-like note → reminder chip appears
- date/time mentioned → calendar chip appears
- coding content → Code Space chip appears
- project content → board/project chip appears

## UI Direction

Avoid heavy metadata tables.

Use subtle inline chips instead:

- + Reminder
- + Calendar
- + Code Space
- + Project
- + Priority

## What to Avoid

Avoid forcing every note into a rigid form.

Avoid making the user choose the perfect category before writing.
