# Code Space

## Purpose

Code Space is a developer-focused workspace mode for coding-related notes, snippets, implementation thinking, and project context.

It should not try to immediately replace VS Code.

It should help the user think with code.

## Core Direction

Code Space should connect:

- code snippets
- implementation notes
- project threads
- repo context
- file context
- future GitHub history

## Layout Direction

Preferred layout:

- restrained file/snippet explorer
- central editor
- linked thread/context panel
- optional output/history panel later

The layout can borrow from VS Code, but should remain calm, glassy, and Noti-like.

## Phase 1

Build:

- embedded editor
- snippet creation
- linked notes beside snippets
- simple file/snippet tree
- local persistence

## Phase 2

Add:

- run/output panel
- snapshots
- version notes
- better keyboard shortcuts

## Phase 3

Add:

- GitHub repo connection
- branch/commit/PR links
- implementation history
- repo-aware context

## What to Avoid

Avoid turning Noti into a generic IDE.

Avoid heavy terminal/build tooling too early.

Avoid losing Noti’s calm spatial identity.
