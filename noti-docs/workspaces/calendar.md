# Calendar Workspace

## Purpose

The Calendar workspace helps users plan time visually while keeping thread context attached.

It should feel familiar like Apple Calendar, but more spatial and interactive.

## Core Direction

Start with a readable week/day layout.

Important features:

- week timeline view
- day view
- inline event creation
- drag-to-create events
- event colour editing
- event deletion/editing
- smooth week transitions
- density/spacing control for time rows
- thread-linked event context

## Visual Feel

Calendar should remain calm and spacious.

Avoid making it look like enterprise scheduling software.

## Interaction Direction

Preferred interactions:

- click and drag to create
- inline event editing where possible
- lightweight popovers
- smooth lateral transitions between weeks
- optional annotation/drawing tools later

## Future Ideas

Possible later additions:

- panoramic week view
- minute-density zoom
- focus mode
- planning annotations
- arrows/highlights/connectors
- thread context embedded inside calendar events

## What to Avoid

Avoid modal-heavy scheduling.

Avoid cluttering the calendar with too many labels or metadata blocks.
