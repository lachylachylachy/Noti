# Reminders Workspace

## Purpose

The Reminders workspace turns lightweight thoughts into actionable items.

It should feel connected to Notes and Calendar, not like a separate task app.

## Core Behaviour

A reminder can originate from:

- a note
- a planning thread
- a calendar event
- a manual reminder entry

Reminders should link back to their source thread where possible.

## UI Direction

Use a calm list/calendar hybrid.

Possible views:

- today
- upcoming
- all
- by thread/project
- calendar-linked reminders

## Interaction Direction

Preferred controls:

- quick complete
- quick reschedule
- priority chip
- linked-thread preview
- optional due date/time

## What to Avoid

Avoid recreating a complex project-management task system too early.

Avoid too many priority/status fields.
